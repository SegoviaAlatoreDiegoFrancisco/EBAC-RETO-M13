# Equipos Fitness

Referente al reto del modulo 13 del curso de desarrollador Frontend. En este repositorio se presenta una Landing page para una tienda de equipos fitness que presenta una nueva linea de productos. Cada producto muestra su imagen, precio, disponibilidad y una ventana (modal) con informacion detallada.

## Tecnologias

- HTML5
- CSS3
- Sass
- Metodologia BEM

## Ver el proyecto

La demo se puede desplegar gratuitamente en Netlify desde este repositorio:

[Desplegar en Netlify]()

Una vez finalizado el despliegue, Netlify generara el enlace publico del proyecto.

## Ejecutar localmente

1. Clona este repositorio.
2. Abre `src/index.html` en el navegador.

Los estilos compilados se encuentran en `css/sass/main.css`.
